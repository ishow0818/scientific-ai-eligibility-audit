# AEA 最小记录模板与示例

版本 1，2026-10-14。本文的审计原则配套材料，不是已校准的自动检测器或统计认证。

## 空白记录

| 字段 | 必填内容 |
| --- | --- |
| 系统与候选身份 | 运行、候选 ID、别名映射；不要用名称差异代替身份核验 |
| 审计集合 | 选择规则、预先指定或事后选取、统计单位 |
| 检查时点 | 轮次、决策前后、观察期限 |
| 有效参与资格 | 明确指实验提名、最终决策或后续测试；不自动代表全部后台计算 |
| 当前资格状态 | ELIGIBLE / INELIGIBLE / NOT_DETERMINABLE；引用实际状态字段或控制流 |
| 资格历史 | 曾否具备资格、退出时刻、触发规则；没有日志不能推断退出事件 |
| 当前评分与历史约束 | 分别记录当前评分和历史资格限制，避免混同 |
| 决策可见证据 | 当时可见数据、来源和哈希；后续结果另列，不追认当时排除 |
| 证据判断规则 | 版本、阈值、拟合方式、多重检查及连续确认条件 |
| 证据状态 | NOT_EXCLUDED / EXCLUDED / NOT_DETERMINABLE；相对于指定规则 |
| 判据可靠性 | 校准程度、适用假设、已知限制 |
| 审计判断 | 分开报告状态失配、退出事件及不能判定项 |
| 干预 | 改变哪些规则、固定哪些观测/拟合/评分；没有干预则不作因果判断 |
| 下游后果 | 真值来源、选择结果、预测误差、评价位置与训练/测量是否重叠 |
| 解释边界 | 选择性筛例、计数相关性、表示代理和数据来源限制 |
| 复核入口 | 代码、输入、日志、版本与哈希；当前哈希不是历史预注册证明 |

## 判定与后果检查规则

1. 最低状态输入为候选身份、资格功能、当前资格记录或可重建状态、同期数据与来源、证据规则及版本。无法核定资格或证据状态时，相关结论记为 NOT_DETERMINABLE。
2. 资格无效且指定规则未排除时，记为相对于该规则的 FI_STATE；另附可靠性等级。操作性规则可执行不等于严格统计校准。
3. FI_EVENT 还要求此前资格有效、当前资格无效及退出当时的证据记录。历史缺失不自动否定可判定的当前状态，但不能推断退出事件。
4. 计算剪枝与 FI 不是互斥类别。预算选择可以合理，同时满足操作性失配条件；不据该标签直接裁定算法不合理或已产生科学损失。
5. 后果检查在拟合与评分完整时，固定数据、参数及评分，对比原集合、全池和证据限定集合。选择改变不自动等于纠错；纠错或损失结论还需要独立真值或适当下游评价。
6. 若退出者已停止计算，须另记补算及成本，不能声称免费恢复。模板不提供检测灵敏度、特异性或自动资格控制的有效性保证。

## 示例 1：Anchor，seed 224，终局 hump 模型

- 示例为原 40 次运行中事后选出的说明性案例，不是新增试验。
- A 的在线资格为 INELIGIBLE，第 6 轮退出；后台拟合和全池评分仍继续。B 的终局资格为 ELIGIBLE。
- 冻结操作性规则下终局 hump 的 excluded=False；这不等于经过严格校准的统计确认。
- 相同观测、逐轮记录及最终参数下，hump 全池权重约为 0.9997789，但 A 的历史资格限制仍有效。
- B 对全部候选统一应用未被操作性规则排除的资格条件，同时也使 quad 不再具备终局资格，不是针对真值恢复。
- A 选择 quad，B 选择 hump；独立测量网格中点上的无噪声预测 RMSE 为 0.7517157 → 0.1447737。
- 后续同一冻结队列的 Open Eligibility 对照在该案例得到与 B 相同的选择和 RMSE。因此，该案例支持终局资格规则影响选择与损失，但未显示证据筛选相对一般全池开放的额外收益，也不证明 χ² 判据严格校准。Open 另纠正 seed 208，而 B 因操作性误排除真实模型未能纠正；不能省略这一反向案例。
- 原记录：evidence_gated_eligibility/outputs/stage2_formal/seed_224.json。

## 示例 2：CoFI，固定候选集合的汇总覆盖

- 这是汇总示例；逐候选审计仍须填入随机种子和候选 ID。186 条记录不等于独立实验数。
- 第 50 轮，最近十轮合格邻域覆盖数量为 Native 0、Control 16。
- 审计对象事先按同一固定观测接收标准筛选，仍符合标准不是新的独立验证。
- 有效资格记为 NOT_DETERMINABLE：窗口零覆盖不能证明明确删除、没有生成尝试或停止全部后续搜索。
- 可报告近期覆盖与固定证据相容范围的分离，不能据此确认 FI 退出事件，也不能用作已验证的 FI 阴性样本。
- 两种完整搜索策略的比较不是单独的资格干预；集合限定于 Control 初始锚点附近，邻域及相邻窗口可重叠。
- 复核入口：analysis/cofi_paired_coverage.json 及其列出的原始日志。

## 示例 3：ARROWS，P2B-01

- 候选路线：Ba2(CuO2)3, BaO, Cu2O, Y2O3。案例从完整基准筛出，不是盲选队列。
- 门控可见的 reference/candidate 600°C 基准指纹一致，原始冗余规则返回 True。
- ON 停止候选 700–900°C 后续测试；OFF 仅关闭该停止条件。这是局部控制流核验，不是历史 campaign 重现。
- 未建立独立的候选科学排除判据，证据排除状态记为 NOT_DETERMINABLE，而非以高温尚未揭示认定未被排除。
- reference 600°C 记录未被上游标为实验验证，且含借用来源说明；不能称两条路线低温状态均经独立实测。
- 决策后揭示的基准 900°C 结果为候选纯相 YBCO、reference 非纯相。这是既有结果，不是新湿实验或决策时可用证据。
- 可报告基准表示下的方向性门控反例，不等同于 Anchor 的操作性 FI 事件或历史发生率。
- 复核入口：arrows_phase2e_gate_verification/outputs、arrows_lowT_provenance_audit/outputs、arrows_strict_directional_audit/outputs。
